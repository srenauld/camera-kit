# Why?

My problem is very simple. I commute around Copenhagen on a bicycle, and I like to record a lot of things. I also happen to have a bike with a Fazua Evation system, which means that, *in theory*, I can extract a lot of data from the bike.

In practice, this is fraught with difficulty:
1. The Fazua app**s** (there are two of them) only allow a very limited subset of functionality, and the one able to record rides is not able to merge with other data (no Health Connect) and only allows export specifically to Strava. The other app also records but exports strictly to GPX, and while it has a lot more useful data than the other one, it also falls short on export.
2. Both the front and back camera I use to make sure I'm safe use proprietary protocols to start things, and even if they didn't, I want to sync the footage later

This repository aims to fix all of this, and in the process, to hopefully provide a way for people to control more DJI camera devices.
